# Spotify Clone 🎵

A modern Spotify-inspired music player web application built with React.  
This project focuses on implementing core Spotify-like functionality, including basic user authorization, music playback, and component-driven UI architecture using modern React features.

## Overview

This project is a Spotify UI clone that allows users to browse songs, view album covers, and play music in a modal audio player.  
It demonstrates the use of React Hooks, Context API for authentication, and reusable components to build a clean and scalable frontend application.

The goal of this project was to practice modern React development patterns, state management, and component-based UI design.

## Features

### 🎧 Music Playback

- Play songs from the interface
- Modal audio player with song artwork
- Custom styled audio controls

### 🔐 Basic Authorization

- Authentication state managed with React Context API
- Global access to user state across components

### ⚛️ Modern React Hooks

- useState
- useEffect
- useContext
- useRef
- Custom state handling patterns

### 🧩 Component-Based Architecture

- Reusable components
- Modular structure
- Clean separation of UI and logic

### 🎨 Responsive UI

- Spotify-inspired design
- Album artwork and song cards
- Interactive play buttons and modal player

## Tech Stack

- React
- JavaScript (ES6+)
- CSS
- React Context API
- React Hooks

## Installation

Clone the repository

```
git clone https://github.com/yourusername/spotify-clone.git
```

Navigate into the project

```
cd spotify-clone
```

Install dependencies

```
npm install
```

Start the development server

```
npm run dev
```

The application will run on:

```
http://localhost:5173
```
